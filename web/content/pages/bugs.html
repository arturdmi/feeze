Bugs

Reporting Bugs

If you encounter bugs or run into problems, we welcome hearing from you since we want to make Feeze work nicely for as many users as possible.

Please post bug reports using Feeze's GitHub Issues tracker.

Issue Labels and Types

Please add adequate labels and set the issue type from the following list:

  • bug — A behavior that is against the specification, causes a crash or is surprising

    cleanup — Code improvements

    enhancement — a request for a new feature, functionality, improvement etc.

    question — Not immediately affects the code but helping solve an unclarity, usually affecting the direction of development and making code future proof

    performance — a problem leading to poor performance (cpu time, memory usage, latency, jitter, any other excessive resource usage)

    uncategorized — an issue that is difficult to fit into any of the other types

    critical — An issue that requires immediate attention to avert major financial, environmental or human damage. This justifies working on the weekend, interrupting your holidays, etc.

    urgent — An issue that requires quick response. This might justify upsetting your partner by coming home late.

Issue Cross-references and Duplicates

Before creating a new issue, try to find similar or related issues. Try not to create duplicate issues and try to add links to related issues.
