Download and Installation

Feeze Releases

Downloadable releases will be published on github under feeze releases.

Installation

From tarball

Installing Feeze from a tarball gives you most control over where feeze will get installed. You will need to unpack the archive using 

    # tar zxf feeze_VERSION_TARGET.tar.gz
where VERSION is the feeze version and TARGET is the target Linux version it was built for. For version 0.001dev build for Ubuntu_24, you will have to use 
    # tar zxf feeze_0.001dev_Ubuntu_24.tar.gz
The result will be a directory with a name like feeze_VERSION_TARGET, so in our example of version 0.001dev build for Ubuntu_24 the directory name will be feeze_0.001dev_Ubuntu_24.

Required Dependencies

To run feeze, you will need to install

  • OpenJDK version 25 or later

    the Java environment used for the GUI, and

  • libgc1.so

    The Boehm-Demers-Weiser's GC that is currently used by Fuzion until an exact GC is available.

Running

To start feeze, run the script feeze in the bin directory of the installation, e.g., using 

    # ./feeze_0.001dev_Ubuntu_24/bin/feeze

For detailed instructions, refer to the documentation.
