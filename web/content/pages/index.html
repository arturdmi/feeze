feeze

Interactive scheduler tracer.

Goal

The goal of feeze is to provide an easy-to-use interactive tool to analyze performance related to scheduling of threads. The focus is on real-time behavior, i.e., finding reasons for performance outliers and fixing these, but it is also a goal to help improve general throughput.

An essential aspect of feeze is an adaptive visualization that dynamically reduces the amount of data displayed to fit the current time resolution and activity. Activities displayed include

  • thread-switches within a process as well as between processes of the same or different users

  • thread-preemption, thread blocking time

  • thread state changes caused by other threads (waking)

Specific tools to find and understand scheduling hotspots, outliers, deadline-misses, etc. will be added to easily navigate the vast amount of scheduling data.

Technology

feeze uses eBPF to hook into kernel level trace events. These events are recorded and stored as compressed data in a shared memory buffer that is accessed a tool showing the feeze GUI.
